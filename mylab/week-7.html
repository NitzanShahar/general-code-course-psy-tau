השבוע נלמד לגרום לקוד לעבוד בשבילנו: בקרת זרימה ופונקציות.

נכתוב תנאים (if / else) כדי שהקוד יפעל אחרת במצבים שונים, ולולאות (for) כדי לחזור על פעולה על הרבה קבצים או נבדקים. אחר כך נכתוב פונקציות משלנו — עם שם, קלט ופלט — ונלמד לאתר שגיאות (debugging).

בחוט של ניהול הקוד נעבוד עם Git מתוך הטרמינל ומתוך RStudio, ובמטלה הזו נעלה את הקוד לראשונה למאגר ב-GitHub.

קוד 3.1פירוק בעיה ופסאודו-קוד

הנחיה למתרגל AI

בשיעור זה ארצה ללמוד לפרק בעיה לצעדים קטנים ולכתוב אותם כפסאודו-קוד, לפני שאני כותב/ת קוד אמיתי.
1. הסבר מהו פסאודו-קוד: תיאור הצעדים של התוכנית במילים פשוטות, שורה אחרי שורה, בלי תחביר של שפה מסוימת. הסבר למה גם מתכנתים מנוסים עושים את זה: קל יותר לחשוב על הלוגיקה בנפרד מהתחביר.
2. הצג את הבעיה: יש קובץ csv עם זמני תגובה של נבדק אחד במטלת סטרופ, בעמודה rt, ואני רוצה את הממוצע. הראה פסאודו-קוד לדוגמה:
step 1: load the file stroop.csv
step 2: take the column rt
step 3: add up all the values
step 4: count how many values there are
step 5: divide the sum by the count
step 6: print the result
הסבר שב-R ובפייתון שלבים 3 עד 5 הם פקודה אחת, אבל החשיבה זהה.
3. שאל אותי מה צריך להוסיף לפסאודו-קוד אם רוצים לחשב את הממוצע רק לניסיונות הנכונים, ורק לזמנים שבין 200 ל-2000 מילישניות. איפה בדיוק להוסיף את הצעד? עצור וחכה. בדוק את התשובה שלי.
4. כתוב את הכותרת "התרגול שלך". בקש ממני לכתוב פסאודו-קוד לבעיה: יש קובץ עם שאלון של 10 פריטים לכל נבדק, בסולם 1 עד 4, ופריטים 3 ו-7 מנוסחים בהיפוך. רוצים ציון כולל לכל נבדק ואת הממוצע של הקבוצה. עצור ובקש ממני להדביק את הפסאודו-קוד.
אם חסר צעד או שהסדר שגוי, העזר בגילוי מודרך עם שאלות, בלי לכתוב לי את הפסאודו-קוד. עצור וחכה שאנסה שוב. אם אבקש, תן לי פתרון לדוגמה.
5. כתוב ששלב הלימוד הסתיים.
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי, ורק אז המשך לשלב הבא.

הנחיה למתרגל AI

בשיעור זה ארצה להבין שני רעיונות מרכזיים בתכנות, החלטה ("אם... אחרת") וחזרה ("לכל..."), קודם במילים ורק בסוף בקוד.

if rt is less than 200:
mark the trial as too fast
otherwise:
keep the trial
הסבר מהם אופרטורי השוואה: גדול, קטן, שווה ושונה.
2. בקש ממני לנסח במילים כלל החלטה משלי: מתי נבדק נכנס לקבוצת "תסמינים גבוהים" לפי ציון בשאלון. עצור וחכה. בדוק שהכלל חד-משמעי (מה קורה בדיוק בציון הגבול?).

load the participant file

save the result

4. הראה איך משלבים: לכל נבדק, לכל ניסוי שלו, אם זמן התגובה קצר מדי, סמן אותו. אחר כך הראה את הרעיון בקוד קצר ב-R ובפייתון, רק כדי שאראה את הדמיון. הסבר שאת התחביר נלמד בהמשך הקורס.
5. כתוב את הכותרת "התרגול שלך". בקש ממני לכתוב פסאודו-קוד: לכל נבדק, אם יותר מ-20% מהניסויים שלו שגויים, הוצא אותו מהניתוח, אחרת חשב את ממוצע זמני התגובה שלו. עצור ובקש ממני להדביק.
אם יש טעות, העזר בגילוי מודרך עם שאלות. אם אבקש, תן לי פתרון לדוגמה.
6. כתוב ששלב הלימוד הסתיים.

# Foundations of programming for empirical science
# Week 7

import os
import pandas as pd
import matplotlib.pyplot as plt


#### LOAD AND MERGE FILES ####

# 1. Read all subject files with a for loop and concatenate them into one data frame
#    (the csv files are in the folder "stroop_data", inside the working folder)
folder_path = "stroop_data"
df_list = []
for file in sorted(os.listdir(folder_path)):
    if file.endswith(".csv"):
        df_temp = pd.read_csv(os.path.join(folder_path, file))
        df_list.append(df_temp)

df = pd.concat(df_list, ignore_index=True)

# 2. Number of subjects and number of conditions
print("Number of subjects:", df["subject"].nunique())
print("Number of conditions:", df["condition"].nunique())

# 3. Number and percent of missing RTs
print("Missing RTs:", df["rt"].isna().sum())
print("Percent missing RTs:", df["rt"].isna().mean() * 100)

# 4. RT histograms for congruent and incongruent trials
for condition in ["congruent", "incongruent"]:
    plt.figure()
    plt.hist(df[df["condition"] == condition]["rt"].dropna(), bins=30)
    plt.title(f"RT - {condition}")
    plt.xlabel("RT (ms)")
    plt.ylabel("Count")
    plt.show()


#### OUTLIERS ####

# 1. A function that flags RTs above mean + 2 SD
def flag_outliers(rt):
    m = rt.mean()
    s = rt.std()
    out = rt > m + 2 * s
    return out

# 2. Loop over subjects: flag each subject's RTs by his own mean and SD,
#    and append the flags to one long list (rows are ordered by subject)
outlier_flags = []
for s in df["subject"].unique():
    rt_subj = df[df["subject"] == s]["rt"]
    outliers_subj = flag_outliers(rt_subj)
    outlier_flags.extend(outliers_subj)

df["outlier"] = outlier_flags


#### PRESENT DATA ####

# 1. Number of outliers per subject
print(df.groupby("subject")["outlier"].sum())

# 2. RT histograms again, after removing the outliers
df_clean = df[df["outlier"] == False]

for condition in ["congruent", "incongruent"]:
    plt.figure()
    plt.hist(df_clean[df_clean["condition"] == condition]["rt"], bins=30)
    plt.title(f"RT - {condition}, outliers removed")
    plt.xlabel("RT (ms)")
    plt.ylabel("Count")
    plt.show()
