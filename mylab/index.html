המחשב, הטרמינל ולוגיקת תכנות

ברוכים הבאים לקורס יסודות התכנות במדע אמפירי!

לפני שכותבים קוד, צריך להבין עם מי מדברים. השבוע נכיר את המחשב מבפנים: מה קורה כשמפעילים תוכנה, איך מסודרים קבצים ותיקיות, ומה זה נתיב. נפתח לראשונה את הטרמינל — חלון שבו מדברים עם המחשב במילים במקום בעכבר — ונלמד בו כמה פקודות בסיסיות.

נכיר גם את החשיבה שמאחורי כל תוכנית: הוראות מדויקות, לפי סדר, שמחשב יכול לבצע. נתקין את כלי העבודה של הקורס (R ו-RStudio, פייתון ו-VS Code, ו-Git), ונריץ סקריפט ראשון בשתי השפות.

השבוע לא צריך לזכור הכול בעל פה. המטרה היא שתרגישו בבית מול המחשב — כל השאר נבנה על זה.

1. שאל אותי שתי שאלות הבנה: (א) כתבתי ניתוח ארוך ולא שמרתי, והמחשב נכבה. מה אבד ולמה? (ב) טענתי קובץ נתונים, מחקתי בקוד נבדק אחד ולא שמרתי. האם הקובץ על הדיסק השתנה? עצור וחכה לתשובה שלי. בדוק שעניתי נכונה ורק אז המשך.

המטלה השבועית

המטלה השבועית (שבוע 1)

במטלה הזו תתרגלו את שלושת הכלים שהכרנו השבוע: הטרמינל, סקריפט ב-R וסקריפט בפייתון. זו המטלה היחידה בקורס שבה עובדים בשתי השפות — מהשבוע הבא בוחרים שפה לכל מטלה.

חלק א - הטרמינל

  1. פתחו טרמינל (ב-Windows: Git Bash; ב-Mac: Terminal) והדפיסו את התיקייה שבה אתם נמצאים.
  2. צרו בתיקיית הבית שלכם תיקייה בשם yesodot, ובתוכה תיקייה בשם week1. היכנסו לתיקייה week1.
  3. צרו בתוך week1 שני קבצים ריקים, hello.R ו-hello.py, והציגו את רשימת הקבצים בתיקייה.
  4. צלמו מסך של הטרמינל שבו רואים את כל הפקודות שהרצתם ואת הפלט שלהן.

חלק ב - סקריפט ראשון ב-R

  1. פתחו את hello.R ב-RStudio, והוסיפו בראשו כותרת בפורמט הקורס (שם הקורס, השבוע, שם ומספר תעודת זהות).
  2. צרו משתנה בשם name עם השם שלכם, ומשתנה בשם age עם הגיל שלכם.
  3. חשבו בכמה ימים בערך חייתם עד היום (הגיל כפול 365), ושמרו את התוצאה במשתנה בשם days.
  4. הדפיסו משפט אחד שמשלב את השם ואת מספר הימים (למשל בעזרת cat או paste).
  5. שמרו את הקובץ והריצו אותו מהטרמינל, מתוך התיקייה week1, עם הפקודה Rscript hello.R. צלמו את הפלט.

חלק ג - אותו סקריפט בפייתון

  1. כתבו ב-hello.py (ב-VS Code) סקריפט שעושה בדיוק את אותו הדבר בפייתון (רמז: print).
  2. הריצו אותו מהטרמינל עם הפקודה python hello.py (ב-Mac לפעמים python3 hello.py). צלמו את הפלט.

חלק ד - לוגיקת תכנות

  1. כתבו בפסאודו-קוד (בעברית, בלי שפת תכנות) אלגוריתם שמקבל רשימה של זמני תגובה של נבדק ומחשב את הממוצע שלהם — בלי להשתמש בפקודה מוכנה לחישוב ממוצע.
  2. כתבו שתי שורות: מה דומה ומה שונה בין הסקריפט ב-R לסקריפט בפייתון.
