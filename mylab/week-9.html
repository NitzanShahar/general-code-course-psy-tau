מידע על סט הנתונים: הקובץ מכיל נתונים אמיתיים על חולי לב.

משתנים:

  1. age : גיל הנבדק
  2. sex : מין הנבדק
  3. restbps : לחץ הדם של הנבדק במנוחה
  4. chol : כולסטרול בדם בעת הבדיקה (mg/L)
  5. bs : רמת סוכר בדם בעת הבדיקה
  6. maxhr : דופק גבוה ביותר שנמד
  7. target : האם אירע לנבדק אירוע לבבי

קובצי נתונים: heart.csv

חלק א – הכנת הנתונים

  1. טענו את קובץ הנתונים וחיקרו את טיבו במספר פקודות
  2. הגדירו משתנה חדש בינארי  המקבל ערך 1 כאשר רמת הסוכר בדם ≥ 120 ו‑0 אחרת.
  3. חלקו את המסד לשני מסדי נתונים:

הראשון יקרא df_training והוא יכיל כ70% מהתצפיות

השני יקרא df_test והוא יכיל כ30% מהתצפיות

  1. וודאו את מספר ואחוז התצפיות בכל מבנה נתונים

חלק ב – התאמת המודל

  1. התאימו מודל רגרסיה לוגיסטית על מסד נתוני האימון (df_training) שבו אירוע לבבי  הוא המשתנה התלוי ואילו שאר המשתנים (כולם או חלקם לבחירתך) בקובץ הם המשתנים המנבאים.

חלק ג – הערכת ביצועים

  1. חשבו את ההסתברויות החזויות למדגם הבדיקה (df_test) עבור כל תצפית.
  2. קודדו משתנה מנובא לסיכוי גבוה / נמוך למחלת לב לפי סף סיכוי של 0.5
  3. הדפיסו Confusion Matrix

בונוס (רשות):

  1. הוסיפו בחלק ב שורת קוד אשר תדפיס את מקדמי הרגרסיה
  2. הוסיפו בחלק ג חישוב של AUC, ואחוזי דיוק עבור אלו שחלו (רגישות) ואלו שלא חלו (סגוליות)
  3. צרו תרשים ROC עבור מדגם הבדיקה. תנו כותרת איור, וכתבו תוויות לצירים: “False Positive Rate” ו‑“True Positive Rate”.

# Foundations of programming for empirical science

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, roc_curve, roc_auc_score


#### DATA PREPARATION ####

# 1. Load the data and explore it
df = pd.read_csv("heart.csv")

print(df.head())
print(df.info())
print(df.describe())
print(df["target"].value_counts())

# 2. Binary variable: 1 if blood sugar >= 120, 0 otherwise
df["bs_high"] = np.where(df["bs"] >= 120, 1, 0)

# 3. Split into training (70%) and test (30%)
df_training, df_test = train_test_split(df, test_size=0.3, random_state=42)

# 4. Number and percent of observations in each data frame
print("Training:", len(df_training), "rows,", round(len(df_training) / len(df) * 100, 1), "%")
print("Test:", len(df_test), "rows,", round(len(df_test) / len(df) * 100, 1), "%")


#### MODEL FITTING ####

# 1. Logistic regression: heart event predicted by the other variables
predictors = ["age", "sex", "restbps", "chol", "bs_high", "maxhr"]
model = LogisticRegression(max_iter=1000)
model.fit(df_training[predictors], df_training["target"])

# 2. Bonus: print the regression coefficients
print("Intercept:", model.intercept_)
print(pd.Series(model.coef_[0], index=predictors))


#### MODEL EVALUATION ####

# 1. Predicted probabilities for the test set
pred_prob = model.predict_proba(df_test[predictors])[:, 1]

# 2. Predicted class by a 0.5 threshold (1 = high risk)
pred_class = np.where(pred_prob >= 0.5, 1, 0)

# 3. Confusion matrix (rows = actual 0/1, columns = predicted 0/1)
cm = confusion_matrix(df_test["target"], pred_class)
print(cm)


#### BONUS ####

# 1. AUC, sensitivity (accuracy for the sick) and specificity (accuracy for the healthy)
print("AUC:", roc_auc_score(df_test["target"], pred_prob))

tn, fp, fn, tp = cm.ravel()
print("Sensitivity:", tp / (tp + fn))
print("Specificity:", tn / (tn + fp))

# 2. ROC curve for the test set
fpr, tpr, thresholds = roc_curve(df_test["target"], pred_prob)
plt.plot(fpr, tpr)
plt.plot([0, 1], [0, 1], linestyle="--")
plt.title("ROC curve - test set")
plt.xlabel("False Positive Rate")
plt.ylabel("True Positive Rate")
plt.show()
