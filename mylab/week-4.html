השבוע נעמיק בעבודה עם טבלאות נתונים. נלמד לשלוף משתנה בודד או תצפית בודדת, למחוק עמודות ושורות, לשנות תא בודד, ולסנן את הטבלה לפי תנאים — למשל רק נבדקות עם IQ גבוה.

נכיר שני סוגי אובייקטים חדשים: משתנה קטגוריאלי (factor / category) ומשתנה לוגי (אמת/שקר), ונפיק סטטיסטיקה תיאורית לפי קבוצות. ב-R נכיר את חבילת dplyr, ובפייתון את הסינון (masking) של pandas. נסיים בתרשים boxplot.

קוד 4.5חבילות: התקנה מול טעינה

הנחיה למתרגל AI

בשיעור זה ארצה להבין מהן חבילות, ומה ההבדל בין להתקין חבילה לבין לטעון אותה. הראה כל דוגמה גם ב-R וגם בפייתון.
1. הסבר שחבילה היא אוסף פונקציות שמישהו כתב ושיתף, שמוסיף לשפה יכולות. השתמש באנלוגיה: התקנה היא לקנות ספר ולשים אותו על המדף, וטעינה היא להוריד אותו מהמדף ולפתוח על השולחן.
2. הדפס והסבר התקנה. ב-R (בקונסולה):
install.packages("psych")
בפייתון (בטרמינל):
python -m pip install pandas
הסבר שבמחברת או ב-Colab כותבים %pip install pandas, שב-Mac כותבים python3 במקום python, ושמתקינים פעם אחת למחשב (החבילה יורדת מ-CRAN או מ-PyPI).
3. הדפס והסבר טעינה. ב-R:
library(psych)
בפייתון:
import pandas as pd
הסבר שטוענים בכל הרצה מחדש, ולכן שורות הטעינה נמצאות בראש הסקריפט, ושורת ההתקנה לא נשארת בסקריפט.
4. הסבר שתי שגיאות נפוצות: חבילה שלא הותקנה (there is no package called ב-R, ModuleNotFoundError בפייתון), וחבילה שהותקנה אבל לא נטענה (could not find function ב-R, NameError בפייתון).
5. שאל אותי: פתחתי את RStudio מחדש והפונקציה describe לא נמצאה, למרות שהתקנתי אתמול את psych. מה שכחתי? בדוק שעניתי נכונה ורק אז המשך.
6. כתוב את הכותרת "התרגול שלך". בקש ממני להתקין ולטעון חבילה בשפה שאבחר, ולהדביק לך את הפלט של בדיקת הגרסה. ב-R:
packageVersion("psych")
ובפייתון:
pd.__version__
עצור וחכה. אם משהו נכשל, עזור לי לפי הודעת השגיאה.
7. כתוב ששלב הלימוד הסתיים.
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי, ורק אז המשך לשלב הבא.

# Foundations of programming for empirical science
# Week 4
# assignment by < First Name > < Last Name >, id < 123456789 >

import pandas as pd
import matplotlib.pyplot as plt


#### EDIT DATA ####

# 1. Load the data from last week and print parts of it
#    (Python counts rows from 0, so row 5 is iloc[4])
df = pd.read_csv("data.csv")

print(df["age"])
print(df.iloc[4])

# 2. Update variables and cells
df = df.drop(columns=["depression"])
df = df.drop(index=[59, 71])              # rows 60 and 72
df = df.reset_index(drop=True)

print(df.loc[9, "age"])                   # row 10
df.loc[9, "age"] = 20
print(df.loc[9, "age"])

# 3. Dimensions, median split and categories
print(df.shape)

df["IQ_group"] = df["iq"] > df["iq"].median()     # True = above the median

df["gender"] = df["gender"].astype("category")
print(df["gender"].cat.categories)

df_girls_high_iq = df[(df["IQ_group"] == True) & (df["gender"] == "female")]


#### PRESENT DATA ####

# 1. Descriptive statistics
print(df[df["IQ_group"] == True]["age"].describe())     # age, high IQ only
print(df.groupby("gender", observed=True)["age"].describe())   # age, separately for each gender

print(df_girls_high_iq.describe(include="all"))         # the second data frame

# 2. Boxplot of anxiety by gender
df.boxplot(column="anxiety", by="gender")
plt.suptitle("")
plt.title("Anxiety by gender")
plt.xlabel("Gender")
plt.ylabel("Anxiety")
plt.show()

# 3. Save as CSV
df.to_csv("data_updated.csv", index=False)
