קוד 4.3מה זה IDE

הנחיה למתרגל AI

בשיעור זה ארצה להבין מהי סביבת עבודה (IDE), ומה היא מוסיפה על הטרמינל שעבדתי בו בשבוע הראשון.
1. הסבר ש-IDE (Integrated Development Environment) היא תוכנה שמרכזת במקום אחד את כל מה שצריך כדי לכתוב ולהריץ קוד. השתמש באנלוגיה של שולחן עבודה במעבדה. אל תכתוב קוד.
2. הסבר את ארבעת החלקים הנפוצים, אחד אחד:
(א) עורך: כותבים ושומרים את הסקריפט.
(ב) קונסולה: המקום שבו הקוד רץ ומופיעות תוצאות ושגיאות.
(ג) סביבה (Environment): רואים אילו משתנים קיימים כרגע בזיכרון.
(ד) קבצים: רואים את התיקייה שבה עובדים.
עצור אחרי כל חלק ובדוק שהבנתי.
3. הסבר את הגשר לשבוע הראשון: ה-Console ב-RStudio הוא בדיוק ה-> שראיתי כשהפעלתי R בטרמינל, והטרמינל המובנה ב-VS Code הוא אותו bash. IDE הוא חלון נוח שמעביר את הקוד שלי לאותו מפרש (R או פייתון), ולא מחליף אותו.
4. הסבר אילו סביבות נפגוש בקורס: RStudio ל-R, VS Code לפייתון (ולמעשה לכל שפה), ו-Google Colab שרץ בדפדפן בלי התקנה. הסבר שהשפה והסביבה הן שני דברים שונים: R היא המנוע, ו-RStudio היא לוח המחוונים.
5. הסבר מה IDE נותן מעבר לפנקס הרשימות: צביעת קוד, השלמה אוטומטית, סימון שגיאות, הרצה של שורה בלחיצה, ותצוגה של משתנים וגרפים. הסבר למה לא כותבים קוד בוורד (הוא מוסיף עיצוב ומשנה מרכאות, וזה שובר קוד).
6. שאל אותי: (א) מה ההבדל בין R ל-RStudio? (ב) כתבתי x = 5 והרצתי. באיזה חלק של המסך אראה ש-x קיים? (ג) מי באמת מחשב את התוצאה כשאני לוחץ/ת Run ב-RStudio? עצור וחכה. בדוק שעניתי נכונה ורק אז המשך.
7. כתוב ששלב הלימוד הסתיים.
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי, ורק אז המשך לשלב הבא.

קוד 4.4התקנת RStudio ו-VS Code

הנחיה למתרגל AI

בשיעור זה ארצה להתקין את סביבות העבודה: RStudio ל-R ו-VS Code לפייתון. R ופייתון כבר מותקנים אצלי מהשבוע הראשון. לווה אותי שלב אחר שלב, ואל תמשיך לפני שבדקנו שהשלב עבד.
1. שאל אותי מה מערכת ההפעלה שלי, ובקש ממני לוודא בטרמינל שפייתון עדיין עונה (python --version, ב-Mac python3 --version). עצור וחכה.
2. RStudio: הדרך אותי להוריד מ-posit.co את RStudio Desktop (הגרסה החינמית) ולהתקין. הסבר ש-RStudio לא כולל את R אלא משתמש ב-R שכבר מותקן, ולכן R חייב להיות מותקן קודם. בקש ממני לפתוח את RStudio ולהריץ בקונסולה:
R.version.string
הסבר שזו אותה גרסה שהטרמינל מפעיל. עצור ובקש ממני להדביק את הפלט.
3. VS Code: הדרך אותי להתקין מ-code.visualstudio.com, ואז להתקין בתוכו את ההרחבות Python ו-Jupyter של Microsoft (Ctrl+Shift+X, ב-Mac Cmd+Shift+X). עצור וחכה שאאשר.
4. בקש ממני לפתוח ב-VS Code טרמינל מובנה (Terminal > New Terminal) ולהריץ בו python --version. הסבר שזה אותו טרמינל שהכרתי, רק בתוך חלון ה-IDE. ב-Windows הדרך אותי לבחור Git Bash כטרמינל ברירת המחדל (Ctrl+Shift+P, ואז Terminal: Select Default Profile). עצור ובקש ממני להדביק את הפלט.
5. אם שלב נכשל, בקש ממני את הודעת השגיאה המלאה ועזור לי לפתור אותה לפני שנמשיך.
6. סכם בטבלה מה הותקן ובאיזו גרסה, וכתוב ששלב הלימוד הסתיים.
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי, ורק אז המשך לשלב הבא.

2. הסבר מהו סקריפט: קובץ טקסט (.R או .py) שבו כותבים את כל הקוד לפי הסדר, שומרים, ומריצים שוב מתי שרוצים. הסבר שזה מה שמאפשר לשחזר ניתוח. הסבר איך מריצים שורה אחת (Ctrl+Enter ב-RStudio, Shift+Enter ב-VS Code; ב-Mac Cmd במקום Ctrl) ואיך מריצים את כל הקובץ.
3. הסבר מהי מחברת (קובץ .ipynb, וב-R גם Quarto או R Markdown): מסמך שמחולק לתאים (cells) של קוד ושל טקסט, והפלט והגרפים מופיעים מתחת לכל תא. הסבר ש-Google Colab ו-Jupyter הן סביבות של מחברות.

5. שאל אותי איזו דרך הכי מתאימה לכל מצב, וחכה לתשובה אחרי כל אחד: (א) לבדוק מהר כמה זה 365 כפול 24. (ב) ניתוח מלא של מטלה שצריך להריץ שוב בשבוע הבא. (ג) דוח שמשלב הסברים, קוד וגרפים. בדוק את התשובות שלי.

בשיעור זה ארצה להבין מהי תיקיית העבודה ב-R ובפייתון, ולמה רוב השגיאות "הקובץ לא נמצא" קשורות אליה. הראה כל דוגמה גם ב-R וגם בפייתון.
1. הזכר לי בקצרה מהו נתיב מלא ומהו נתיב יחסי. הסבר שכשאני כותב/ת בקוד רק שם של קובץ, R או פייתון מחפשים אותו בתיקיית העבודה.
2. הדפס והסבר איך בודקים מהי תיקיית העבודה. ב-R:
getwd()
ובפייתון:
import os
os.getcwd()
בקש ממני להריץ באחת השפות ולהדביק את הפלט. עצור וחכה.
3. הדפס והסבר איך משנים אותה, ולמה זה פתרון שביר (הנתיב שלי לא קיים במחשב של אחרים). ב-R:
setwd("C:/Users/dana/course/week3")
ובפייתון:
os.chdir("C:/Users/dana/course/week3")
4. הסבר את הפתרון המומלץ: תיקייה אחת לכל עבודה, ובה הסקריפט ותת-תיקייה data. ב-RStudio פותחים פרויקט (File > New Project) ותיקיית העבודה נקבעת לבד. ב-VS Code פותחים את התיקייה (File > Open Folder). ואז קוראים בנתיב יחסי. ב-R:
df = read.csv("data/stroop.csv")
ובפייתון:
import pandas as pd
df = pd.read_csv("data/stroop.csv")
5. שאל אותי: קיבלתי שגיאה שהקובץ לא נמצא. אילו שני דברים אבדוק קודם? בדוק שעניתי נכונה.

אם טעיתי, העזר בגילוי מודרך עם טקסט ללא קוד כדי לעזור לי להצליח. עצור וחכה שאנסה שוב.
אם אבקש, תן לי את הפתרון.
7. כתוב ששלב הלימוד הסתיים.

קוד 4.7חבילות: התקנה מול טעינה

הנחיה למתרגל AI

בשיעור זה ארצה להבין מהן חבילות, ומה ההבדל בין להתקין חבילה לבין לטעון אותה. הראה כל דוגמה גם ב-R וגם בפייתון.
1. הסבר שחבילה היא אוסף פונקציות שמישהו כתב ושיתף, שמוסיף לשפה יכולות. השתמש באנלוגיה: התקנה היא לקנות ספר ולשים אותו על המדף, וטעינה היא להוריד אותו מהמדף ולפתוח על השולחן.
2. הדפס והסבר התקנה. ב-R (בקונסולה):
install.packages("psych")
בפייתון (בטרמינל):
python -m pip install pandas
הסבר שבמחברת או ב-Colab כותבים %pip install pandas, שב-Mac כותבים python3 במקום python, ושמתקינים פעם אחת למחשב (החבילה יורדת מ-CRAN או מ-PyPI).
3. הדפס והסבר טעינה. ב-R:
library(psych)
בפייתון:
import pandas as pd
הסבר שטוענים בכל הרצה מחדש, ולכן שורות הטעינה נמצאות בראש הסקריפט, ושורת ההתקנה לא נשארת בסקריפט.
4. הסבר שתי שגיאות נפוצות: חבילה שלא הותקנה (there is no package called ב-R, ModuleNotFoundError בפייתון), וחבילה שהותקנה אבל לא נטענה (could not find function ב-R, NameError בפייתון).
5. שאל אותי: פתחתי את RStudio מחדש והפונקציה describe לא נמצאה, למרות שהתקנתי אתמול את psych. מה שכחתי? בדוק שעניתי נכונה ורק אז המשך.
6. כתוב את הכותרת "התרגול שלך". בקש ממני להתקין ולטעון חבילה בשפה שאבחר, ולהדביק לך את הפלט של בדיקת הגרסה. ב-R:
packageVersion("psych")
ובפייתון:
pd.__version__
עצור וחכה. אם משהו נכשל, עזור לי לפי הודעת השגיאה.
7. כתוב ששלב הלימוד הסתיים.
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי, ורק אז המשך לשלב הבא.

# Foundations of programming for empirical science
# Week 4
# assignment by < First Name > < Last Name >, id < 123456789 >

import pandas as pd
import matplotlib.pyplot as plt


#### EDIT DATA ####

# 1. Load the data from last week and print parts of it
#    (Python counts rows from 0, so row 5 is iloc[4])
df = pd.read_csv("data.csv")

print(df["age"])
print(df.iloc[4])

# 2. Update variables and cells
df = df.drop(columns=["depression"])
df = df.drop(index=[59, 71])              # rows 60 and 72
df = df.reset_index(drop=True)

print(df.loc[9, "age"])                   # row 10
df.loc[9, "age"] = 20
print(df.loc[9, "age"])

# 3. Dimensions, median split and categories
print(df.shape)

df["IQ_group"] = df["iq"] > df["iq"].median()     # True = above the median

df["gender"] = df["gender"].astype("category")
print(df["gender"].cat.categories)

df_girls_high_iq = df[(df["IQ_group"] == True) & (df["gender"] == "female")]


#### PRESENT DATA ####

# 1. Descriptive statistics
print(df[df["IQ_group"] == True]["age"].describe())     # age, high IQ only
print(df.groupby("gender", observed=True)["age"].describe())   # age, separately for each gender

print(df_girls_high_iq.describe(include="all"))         # the second data frame

# 2. Boxplot of anxiety by gender
df.boxplot(column="anxiety", by="gender")
plt.suptitle("")
plt.title("Anxiety by gender")
plt.xlabel("Gender")
plt.ylabel("Anxiety")
plt.show()

# 3. Save as CSV
df.to_csv("data_updated.csv", index=False)
