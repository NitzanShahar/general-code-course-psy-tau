חלק א - וקטורים ומטריצות

  1. צרו שני וקטורים, עם 15 ערכים בכל אחד:

חלק ב - סטטיסטיקה במטריצה

  1. הדפיסו את הממוצע של כל עמודה ב-m, ואת הסכום של כל שורה ב-m.

חלק ג - לולאות ותנאים

  1. כתבו לולאת for שעוברת על הערכים של x2, ובעזרת תנאי if סופרת כמה מהם גדולים מ-50. שמרו את הספירה במשתנה בשם n_high, והדפיסו אותו.

import numpy as np


#### VECTORS AND MATRICES ####

# 1. Two vectors of 15 values
x1 = np.random.normal(loc=50, scale=10, size=15)
x2 = np.random.uniform(low=0, high=100, size=15)

# 2. Combine them into a matrix (each vector is a column)
m = np.column_stack((x1, x2))
print(m)

# 3. Multiply by a scalar, and add the two matrices
m2 = m * 2
print(m + m2)

# 4. Print and change the value in row 4, column 2 (Python counts from 0)
print(m[3, 1])
m[3, 1] = 100
print(m)

# 5. Row 5 and column 1
row5 = m[4, :]
col1 = m[:, 0]
print(row5)
print(col1)


#### STATISTICS WITH MATRICES ####

# 1. The mean of each column (axis=0) and the sum of each row (axis=1)
print(m.mean(axis=0))
print(m.sum(axis=1))


#### LOOPS AND CONDITIONS ####

# 1. Count the values of x2 above 50
n_high = 0
for value in x2:
    if value > 50:
        n_high = n_high + 1
print(n_high)

# 2. The larger of the two values in each row of m
row_max = []
for i in range(15):
    if m[i, 0] > m[i, 1]:
        row_max.append(m[i, 0])
    else:
        row_max.append(m[i, 1])
row_max = np.array(row_max)
print(row_max)

# 3. The same test on a whole vector at once, without a loop
group = np.where(x1 > 50, "high", "low")
print(group)


#### FUNCTIONS ####

# 1. Count the values of x above a threshold
def count_above(x, threshold):
    n = 0
    for value in x:
        if value > threshold:
            n = n + 1
    return n

# 2. Use the function (the first result equals n_high)
print(count_above(x2, 50))
print(count_above(x1, 60))
