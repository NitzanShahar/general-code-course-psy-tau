בעיות קלסיפיקציה א: KNN וכיוונון המודל

השבוע נכיר מודל סיווג חדש ואינטואיטיבי מאוד: KNN (K השכנים הקרובים). כדי לסווג נבדק חדש, המודל מסתכל על הנבדקים הדומים לו ביותר ושואל — לאיזו קבוצה רובם שייכים?

למודל יש פרמטר אחד, K, שקובע בכמה שכנים להתחשב. נלמד לבחור אותו בצורה מושכלת: בלולאה שמאמנת את המודל עם כל ערך של K, בודקת את הדיוק על סט בדיקה, ומציגה את התוצאות בגרף. זה בדיוק התהליך שנקרא כיוונון היפר-פרמטרים.

נעבוד עם נתונים על שלושה זנים של פינגווינים — ונראה כמה טוב אפשר לנחש זן לפי מידות המקור והכנף.

הנחיה למתרגל AI

אני לומד/ת מודלים לסיווג (קלסיפיקציה) בשפת R. בשיעור זה ארצה להבין את הרעיון של מודל KNN (K-Nearest Neighbors), בלי לכתוב קוד.
1. הסבר לי מה זו בעיית סיווג, בדוגמה מפסיכולוגיה: לנבא אם נבדק מדוכא או לא לפי שעות השינה וזמן התגובה שלו. הסבר את ההבדל בין סיווג (קטגוריה) לבין ניבוי של ערך רציף. עצור וחכה לתשובה שלי.
2. מה זה "שכנים קרובים"? תאר לי מישור דו-ממדי שבו ציר אחד הוא שעות שינה והציר השני הוא זמן תגובה, וכל נבדק הוא נקודה. הסבר במילים מה זה מרחק בין שתי נקודות.

4. מה המשמעות של K? מה קורה עם K=1 לעומת K=15? שאל אותי מה החיסרון של K קטן מדי ושל K גדול מדי. בדוק שעניתי נכונה ורק אז המשך.
5. הסבר ש-KNN לא לומד משוואה כמו רגרסיה לוגיסטית, אלא שומר את נתוני האימון ומשווה אליהם כל נבדק חדש. הסבר גם, בלי קוד, למה חשוב שכל המשתנים יהיו באותו סדר גודל (שעות שינה לעומת מילישניות). נלמד לתקן זאת ביחידה הבאה.
6. עצור ותן לי דוגמה לבעיה אחרת במחקר בפסיכולוגיה שבה KNN יכול לעזור, ושאל אותי מה יהיו המשתנים בה. אם עניתי נכונה, כתוב ששלב הלימוד הסתיים.

R 11.2מודל KNN ב-R

הנחיה למתרגל AI

אני לומד/ת מודלים לסיווג (קלסיפיקציה) בשפת R. בשיעור זה ארצה ללמוד להריץ מודל KNN עם הפונקציה knn מחבילת class, ולהבין למה צריך לתקנן משתנים עם scale.
1. הדפס את הקוד הבא, שיוצר נתונים מדומים של 300 נבדקים ומחלק אותם לסט אימון (200) וסט מבחן (100), והסבר אותו בקצרה:
set.seed(7)
n = 300
sleep_hours = rnorm(n, mean = 7, sd = 1)
rt_ms = rnorm(n, mean = 600, sd = 100)
age = runif(n, 20, 40)
depressed = ifelse(2 * (7 - sleep_hours) + (rt_ms - 600) / 100 + rnorm(n) > 1.5, "yes", "no")
df = data.frame(sleep_hours, rt_ms, age, depressed)
train_rows = sample(1:n, 200)
train = df[train_rows, ]
test = df[-train_rows, ]
2. הדפס את הקוד הבא והסבר את train, test, cl ו-k. הסבר ש-knn מחזירה ישר ניבויים לסט המבחן, בלי שלב אימון נפרד:
library(class)
predictors = c("sleep_hours", "rt_ms")
pred = knn(train = train[, predictors], test = test[, predictors], cl = train$depressed, k = 5)
mean(pred == test$depressed)
3. שאל אותי: שעות שינה משתנות בכמה שעות וזמן תגובה במאות מילישניות. איזה משתנה ישלוט במרחק? בדוק שעניתי נכונה ורק אז המשך.
4. הסבר מה עושה scale (ממוצע 0 וסטיית תקן 1), הדפס את הקוד הבא והסבר למה הדיוק השתנה:
x = scale(df[, predictors])
pred_z = knn(train = x[train_rows, ], test = x[-train_rows, ], cl = train$depressed, k = 5)
mean(pred_z == test$depressed)
5. כתוב את הכותרת "התרגול שלך". בקש ממני להריץ את המודל המתוקנן עם k = 1 ועם k = 25 ולהשוות את הדיוק. עצור ובקש ממני להדביק לך את הקוד. אם טעיתי, העזר בגילוי מודרך עם טקסט ללא קוד. אם אבקש, תן לי את הפתרון.
6. כתוב ששלב הלימוד הסתיים.
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי, ורק אז המשך לשלב הבא.

R 11.3בחירת K בלולאה

הנחיה למתרגל AI

אני לומד/ת מודלים לסיווג (קלסיפיקציה) בשפת R. בשיעור זה ארצה ללמוד לבחור את K של מודל KNN בעזרת לולאה (כיוונון היפר-פרמטר).
1. הסבר במילים מה ההבדל בין פרמטר שהמודל לומד (כמו מקדם ברגרסיה) להיפר-פרמטר שאנחנו בוחרים (כמו K). עצור וחכה לתשובה שלי.
2. הדפס את הקוד הבא (נתונים מדומים, חלוקה לאימון ומבחן ותקנון) ובקש ממני להריץ אותו:
set.seed(7)
n = 300
sleep_hours = rnorm(n, mean = 7, sd = 1)
rt_ms = rnorm(n, mean = 600, sd = 100)
age = runif(n, 20, 40)
depressed = ifelse(2 * (7 - sleep_hours) + (rt_ms - 600) / 100 + rnorm(n) > 1.5, "yes", "no")
df = data.frame(sleep_hours, rt_ms, age, depressed)
train_rows = sample(1:n, 200)
train = df[train_rows, ]
test = df[-train_rows, ]
library(class)
library(ggplot2)
x = scale(df[, c("sleep_hours", "rt_ms")])
3. הדפס את הלולאה הבאה והסבר כל שורה, בדגש על שמירת הדיוק של כל K בוקטור accuracy:
k_values = 1:30
accuracy = c()
for (k in k_values) {
pred = knn(train = x[train_rows, ], test = x[-train_rows, ], cl = train$depressed, k = k)
accuracy[k] = mean(pred == test$depressed)
}
results = data.frame(k = k_values, accuracy = accuracy)
ggplot(results, aes(x = k, y = accuracy)) + geom_line() + geom_point()
k_values[which.max(accuracy)]
שאל אותי מה אני רואה בגרף ב-K קטן מאוד וב-K גדול מאוד. בדוק שעניתי נכונה ורק אז המשך.
4. הסבר שבחירת K לפי סט המבחן נותנת דיוק אופטימי מדי, ושעדיף cross-validation על סט האימון, למשל עם knn.cv(train, cl, k).
5. כתוב את הכותרת "התרגול שלך". בקש ממני לשנות את הלולאה כך שתשתמש ב-knn.cv על סט האימון, לבחור K, ורק אז לבדוק אותו פעם אחת על סט המבחן. עצור ובקש ממני להדביק לך את הקוד. אם טעיתי, העזר בגילוי מודרך עם טקסט ללא קוד. אם אבקש, תן לי את הפתרון.
6. כתוב ששלב הלימוד הסתיים.
עשה את השלבים האלו אחד אחד לפי הסדר. עצור בסוף כל שלב לראות שהבנתי, ורק אז המשך לשלב הבא.

library(ggplot2)
library(class)


#### EXPLORE DATA ####

# 1. Load the data, remove missing values, describe
df = read.csv("penguins.csv")
df = na.omit(df)

dim(df)
summary(df)
table(df$species)

# 2. Scatter plot of two continuous variables, colored by species
ggplot(df, aes(x = bill_depth_mm, y = flipper_length_mm, color = species)) +
  geom_point() +
  labs(title = "Bill depth and flipper length by species",
       x = "Bill depth (mm)", y = "Flipper length (mm)")


#### KNN MODEL ####

# 1. Seed, 80/20 split, the two predictors apart from the target
set.seed(42)
n           = nrow(df)
train_index = sample(1:n, size = round(0.8 * n))

predictors = c("bill_depth_mm", "flipper_length_mm")
x_train = df[train_index, predictors]
x_test  = df[-train_index, predictors]
y_train = df$species[train_index]
y_test  = df$species[-train_index]

# 2. Standardize by the mean and sd of the training set
# Why: KNN classifies by the distance between penguins. Without standardization,
# the variable with the larger spread dominates the distance: flipper length
# varies by tens of mm, bill depth only by a few mm, so bill depth hardly counts.
train_mean = colMeans(x_train)
train_sd   = apply(x_train, 2, sd)

x_train_s = scale(x_train, center = train_mean, scale = train_sd)
x_test_s  = scale(x_test,  center = train_mean, scale = train_sd)

# 3. Loop over K = 1..20: train, predict the test set, save the accuracy
k_values = 1:20
accuracy = rep(NA, length(k_values))

for (k in k_values) {
  pred        = knn(train = x_train_s, test = x_test_s, cl = y_train, k = k)
  accuracy[k] = mean(pred == y_test)
}

# 4. Plot accuracy by K, with the best K marked in red
best_k  = which.max(accuracy)          # if several K tie, which.max takes the smallest
results = data.frame(k = k_values, accuracy = accuracy)

ggplot(results, aes(x = k, y = accuracy)) +
  geom_line() +
  geom_point() +
  geom_point(data = results[best_k, ], color = "red", size = 4) +
  labs(title = "KNN test accuracy by K",
       x = "K (number of neighbors)", y = "Accuracy")

# 5. Print the best K and its accuracy
cat("Best K:", best_k, "accuracy:", accuracy[best_k], "\n")


#### BONUS ####

# 1. The same loop without standardization
accuracy_raw = rep(NA, length(k_values))

for (k in k_values) {
  pred            = knn(train = x_train, test = x_test, cl = y_train, k = k)
  accuracy_raw[k] = mean(pred == y_test)
}

print(round(accuracy_raw, 3))
# The best accuracy is lower: without standardization the distance is almost only
# flipper length, so the model nearly ignores bill depth, which helps to separate
# the species.

# Foundations of programming for empirical science
# Week 10
# assignment by < First Name > < Last Name >, id < 123456789 >

import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier


#### EXPLORE DATA ####

# 1. Load the data, remove missing values, describe
df = pd.read_csv("penguins.csv")
df = df.dropna()

print(df.shape)
print(df.describe())
print(df["species"].value_counts())

# 2. Scatter plot of two continuous variables, colored by species
sns.scatterplot(data=df, x="bill_depth_mm", y="flipper_length_mm", hue="species")
plt.title("Bill depth and flipper length by species")
plt.xlabel("Bill depth (mm)")
plt.ylabel("Flipper length (mm)")
plt.show()


#### KNN MODEL ####

# 1. Seed (random_state), 80/20 split, the two predictors apart from the target
df_train, df_test = train_test_split(df, test_size=0.2, random_state=42)

predictors = ["bill_depth_mm", "flipper_length_mm"]
x_train = df_train[predictors]
x_test  = df_test[predictors]
y_train = df_train["species"]
y_test  = df_test["species"]

# 2. Standardize by the mean and sd of the training set
# Why: KNN classifies by the distance between penguins. Without standardization,
# the variable with the larger spread dominates the distance: flipper length
# varies by tens of mm, bill depth only by a few mm, so bill depth hardly counts.
train_mean = x_train.mean()
train_sd   = x_train.std()

x_train_s = (x_train - train_mean) / train_sd
x_test_s  = (x_test - train_mean) / train_sd

# 3. Loop over K = 1..20: train, predict the test set, save the accuracy
k_values = list(range(1, 21))
accuracy = []

for k in k_values:
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(x_train_s, y_train)
    accuracy.append(model.score(x_test_s, y_test))

# 4. Plot accuracy by K, with the best K marked in red
best_index = np.argmax(accuracy)        # if several K tie, argmax takes the smallest
best_k = k_values[best_index]

plt.plot(k_values, accuracy, marker="o")
plt.scatter(best_k, accuracy[best_index], color="red", s=120, zorder=3)
plt.title("KNN test accuracy by K")
plt.xlabel("K (number of neighbors)")
plt.ylabel("Accuracy")
plt.xticks(k_values)
plt.show()

# 5. Print the best K and its accuracy
print("Best K:", best_k, "accuracy:", accuracy[best_index])


#### BONUS ####

# 1. The same loop without standardization
accuracy_raw = []

for k in k_values:
    model = KNeighborsClassifier(n_neighbors=k)
    model.fit(x_train, y_train)
    accuracy_raw.append(model.score(x_test, y_test))

print(np.round(accuracy_raw, 3))
# The best accuracy is lower: without standardization the distance is almost only
# flipper length, so the model nearly ignores bill depth, which helps to separate
# the species.
